# Przeprogramowani.pl

Statyczna strona Astro z komponentami React i Tailwind CSS.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run check
npm run build
```

Wynik znajduje się w `dist/`. Projekt jest skonfigurowany pod Cloudflare Pages: ustaw komendę builda na `npm run build`, katalog wyjściowy na `dist` albo wdrażaj przez `wrangler` z użyciem `wrangler.toml`.
